# F5.0-FE-ATOMIC-01 — Recriação Atômica do Frontend (Spec v1.0)

## 1. Contexto e Decisão
- Gatilhos: VETO à copy falha (matemática 8.37≠8.5, claims sem evidência) + fronteira de runtime Deno/Node + legado Stitch.
- Decisão: recriar o frontend de forma atômica, docs-first, com gates por camada.
- Escopo: `src/app/**`, `src/components/**`, `src/lib/**`, `tsconfig.json` (fronteira), rota `/waitlist`.
- Fora de escopo (intocável): `src/core/**`, `src/adapters/**`, `supabase/functions/**`.

## 2. Princípios
1. Docs-first: nenhum código sem contrato nesta spec.
2. Átomo = unidade mínima verificável isoladamente.
3. Claims: só renderiza claim com evidência (Registro §3).
4. Fronteira: Next.js não type-checka nem importa código Deno.
5. Commit atômico por camada, com evidência e COMMIT-AUTH explícito.

## 6. Fitness (D-FITNESS)
- Build C6 verde em L0 e L4 (obrigatório).
- TS estrito; zero libs UI externas; SVG inline apenas.
- Dark parity; contraste WCAG AA; aria-label em controles sem texto.
- Complexidade por componente ≤ 10.
- Auditoria de claims: 0 claims bloqueados no render final.
- Matemática exibida: soma dos pesos = total exibido (8.50).

## 7. Governança
Por átomo: EXEC (script bounded, 1 arquivo por vez) → autochecagem → evidência colada.
Por camada: Projetista emite `Lx-COMMIT-AUTH` com comandos git exatos.
Push: proibido até `L4-COMMIT-AUTH` + auditoria final de claims.

## 8. Crítica (4 lentes)
- Trad: risco de descartar Navbar/WaitlistForm funcionais → mitigado por A2 = verificar-preservar.
- Mod: overhead de 14 átomos pode atrasar MVP → mitigado por commits por camada (5 commits).
- Fut: tokens + contratos habilitam i18n/temas; registro de claims governa marketing futuro.
- Longo: docs-first garante auditabilidade 20a; drift mitigado por versionamento (§9).

## 9. Suposições, Falhas, Versionamento
Suposições: (S1) WaitlistForm/Navbar existem e renderizam 200; (S2) único bloqueio de build é a fronteira tsconfig; (S3) frontend não importa core/adapters (Script J vazio).
Falhas: (F1) ordem de camadas violada → gate bloqueia; (F2) drift de copy → auditoria A14; (F3) allowImportingTsExtensions mascarar erro real → core permanece excluído do type-check Node e validado no Deno/testes; (F4) drift de docs → spec versionada.
Versionamento: spec F5.0-FE-ATOMIC-01 v1.0 · copy_v1 · score_v1 (0.35/0.35/0.30) · design_v1.
